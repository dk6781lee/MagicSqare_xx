## 1. Mom Test 최종 결과

### 페르소나

4×4 격자, 빈칸 2개(`0`), 1~16, 합 **34**를 맞추는 **학습자** (손으로/코드로 다룸).

### Mom Test 증거 3줄 (인용)

1. “지난주 OO 과제에서 빈칸 2개 넣고”
2. “행·열·대각선 합 맞췄는데 대각선 하나를 빼먹어서”
3. “20분 날렸다.”

### 인터뷰 답변 (과거 사실만)

> “지난주 OO 과제에서 빈칸 2개 넣고 행·열·대각선 합 맞췄는데 대각선 하나를 빼먹어서 20분 날렸다.”

※ 슬라이드·ECB 클래스 나열은 **과제 참고**이며 Mom Test 인용이 아님 → `01.MagicSquare_ProblemDefinition_Report.md` §5

### 진짜 문제 (한 문장, 확정)

빈 칸 2개를 채운 뒤 **행·열·대각선이 모두 34인지** 스스로 확신하지 못해, 검증에서 **한 줄(예: 대각선)을 빼먹으면** 맞춘 줄 알고 **시간을 낭비(예: 20분)** 한 뒤 다시 맞춰야 한다.

### 표면 문제 (솔루션 섞임 — 하지 않을 것)

- “4×4 마방진 **검증 프로그램**을 만든다.”
- “빈칸을 자동으로 채우는 **Solver 앱**을 만든다.”
- “`Solver`에 알고리즘만 넣으면 과제가 끝난다.”
- “빈 칸 두 개는 34에서 **행 합만** 빼면 된다.”
- “`GridUI`에서 입력받고 바로 격자 배열을 수정하면 된다.”
- “실패 조건은 ‘틀리면 false’ **하나**면 충분하다.”

## 2. Mom Test 인터뷰 로그

**규칙:** 질문 1개씩 · 과거 사실 · 솔루션/기능 제안 금지

### Q1

가장 최근에 **빈 칸이 남아 있는 4×4 마방진**을 손으로 풀었거나 코드로 다룬 적이 있나요? **언제**, **왜**.

### A1 ✅

> 지난주 OO 과제에서 빈칸 2개 넣고 행·열·대각선 합 맞췄는데 대각선 하나를 빼먹어서 20분 날렸다.

| 항목 | 평가 |
|------|------|
| 과거·특정 | ✅ 지난주 OO 과제 |
| 행동 | ✅ 빈칸 2, 합 맞춤 시도 |
| 실수 | ✅ 대각선 1개 누락 |
| 비용 | ✅ 20분 |
| 솔루션 섞임 | 없음 |

### Q2 (미답 — 추궁 권장)

그 20분 동안 대각선 누락을 **처음 알게 된 순간**에 무엇을 보고 있었는지, 직전까지 **행·열만** 더했는지 (yes/no).
