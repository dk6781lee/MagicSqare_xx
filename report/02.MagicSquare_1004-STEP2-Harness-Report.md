### 2.3 `.cursorrules` 요약 (SSOT for AI)

| 영역 | 규칙 |
|------|------|
| **도메인** | 4×4, 빈칸 `0`×2, 1~16, 합 **34**; 출력 `int[6]` `[r1,c1,n1,r2,c2,n2]` **1-index** |
| **오류** | E001~E007 → **boundary**; **entity는 E001~E005 처리 금지** |
| **상수** | MagicConstant SSOT — `34`/`16` 리터럴 산재 금지 |
| **ECB** | boundary→control→entity; entity→\* import 금지 |
| **Dual-Track** | Logic `D-*` / `test_d_*` (Mock 금지); UI `U-*` / `test_u_*` (Mock 허용) |
| **TDD** | RED→GREEN→REFACTOR; assert 완화·skip·xfail 금지 |
| **AI** | 한국어; Phase/Layer/Track 선언; commit은 사용자 요청 시만 |

### 2.4 Dual-Track 매핑

| Track | Layer | 테스트 ID | 파일명 | 1차 범위 |
|-------|-------|-----------|--------|----------|
| Logic | entity, control | `D-*` | `test_d_*.py` | Control **우선** (C1–C3) |
| UI | boundary | `U-*` | `test_u_*.py` | 후속 (`GridUI` 등) |
