### 3.1 Track B — Logic (entity)

**묶음:** `D-LOC-01` (FR-LOC-01)

| Test ID | 대상 함수 | Given→Then | Invariant |
|---------|-----------|------------|-----------|
| **D-LOC-01** | `find_blank_coords()` | G1 → `[(2,2),(3,3)]` 1-index | I6 row-major |
| D-MIS-01 | `find_not_exist_nums()` | G1 → `[7,10]` | I7, I11 |
| D-VAL-01 | `is_magic_square()` | G0 → `True` | I1~I5 |

**C2C (Rule 1~3 = PRD R1~R3)**

| Rule | PRD | FR-LOC-01 연결 |
|------|-----|----------------|
| R1 | 4×4 | 입력 격자 전제 |
| R2 | {0}∪[1,16] | 빈칸 = `0` |
| R3 | 빈칸 2개 | 좌표 2개 반환 |

**G1 fixture (conftest용 데이터)**

