## 1. 개요

### 1.1 배경

4×4 마방진 과제에서 학습자는 빈칸 2개를 채운 뒤 행·열·대각선 합 34를 맞춰야 한다. Mom Test에 따르면 **검증 누락(특히 대각선)** 으로 잘못된 “완료” 판정 후 **약 20분** 재작업이 발생했다.

### 1.2 목표 (한 문장)

빈칸 2개가 있는 4×4 격자에서, **완료로 믿기 전에** 10개 라인(행4·열4·대각2)이 모두 합 34인지 **판정**할 수 있는 규칙·명령을 테스트로 고정한다.

### 1.3 비목표 (이번 릴리스)

- 마방진 **자동 완성(Solver)** 제품화  
- **GridUI** 완성형 앱  
- “틀리면 false” 단일 응답만 제공  
- 행·열만 검사하는 **행합 계산기** 수준으로 끝내기  

---

## 2. 사용자 · 문제

### 2.1 페르소나

4×4 격자, 빈칸 2개(`0`), 1~16, 합 **34**를 맞추는 학습자.

### 2.2 진짜 문제

빈 칸 2개를 채운 뒤 행·열·대각선이 모두 34인지 스스로 확신하지 못해, 검증에서 한 줄(예: 대각선)을 빼먹으면 맞춘 줄 알고 시간을 낭비(예: 20분) 한 뒤 다시 맞춰야 한다.

### 2.3 Mom Test 증거

| # | 인용 |
|---|------|
| 1 | “지난주 OO 과제에서 빈칸 2개 넣고” |
| 2 | “행·열·대각선 합 맞췄는데 대각선 하나를 빼먹어서” |
| 3 | “20분 날렸다.” |

## 3. R-G-I-O

| 항목 | 설명 |
|------|------|
| **Role** | 4×4 부분 마방진을 채우고 **완료 판정**을 내리는 학습자 |
| **Goal** | 10라인 합=34를 빠짐없이 확인; 한 줄이라도 어긋나면 “완료” 확신 금지 |
| **Input** | 4×4 `int[][]` (또는 동등 구조), `0`×2 + 1~16 일부 |
| **Output** | 전체 상태: `COMPLETE` / `INCOMPLETE` / `INVALID` + **실패 라인 ID 목록** |

---

## 4. 도메인 규칙 (Rule)

| ID | 규칙 |
|----|------|
| R1 | 격자 크기 4×4 |
| R2 | 셀 값 ∈ {0} ∪ [1, 16] |
| R3 | `0`(빈칸) 개수 = **2** |
| R4 | 0이 아닌 값은 **중복 없음** |
| R5 | **10라인** 각각 합 = **34** (행 H0–H3, 열 V0–V3, 대각 D0·D1) |
| R6 | R3–R5 만족 시에만 `CanClaimComplete = true` |

### 4.1 라인 ID

| ID | 설명 |
|----|------|
| H0–H3 | 행 0–3 |
| V0–V3 | 열 0–3 |
| D0 | 주대각 (0,0)→(3,3) |
| D1 | 부대각 (0,3)→(3,0) |

## 5. 기능 요구 (Command)

| ID | 명령 | 설명 |
|----|------|------|

- `lineId` → 좌표 목록  
- (선택) 사용되지 않은 1~16 집합 — 검증 보조만
